# Lizenz und Nutzungsbedingungen für die verwendeten Daten

Die in diesem Projekt verwendeten Daten stammen aus der offiziellen EU‑Open‑Data‑Plattform:

🔗 https://data.europa.eu/data/datasets/ted-csv/

---

## 1. Lizenz

Die Daten unterliegen der **EU Open Data Licence**.  
Sie dürfen frei verwendet, analysiert, verarbeitet und visualisiert werden, sofern die folgenden Bedingungen erfüllt sind:

- **Quellenangabe ist verpflichtend**  
  *“Source: Tenders Electronic Daily (TED), data.europa.eu”*

- Die Daten dürfen **nicht** zur Identifikation einzelner Personen oder Unternehmen verwendet werden.

- Die Daten dürfen **nicht** für Zwecke genutzt werden, die gegen Datenschutz‑ oder Wettbewerbsrecht verstoßen.

---

## 2. Einschränkungen und Hinweise

- Die Daten können **fehlende Werte**, **Duplikate** oder **Inkonsistenzen** enthalten.  
- Die Daten spiegeln reale Verwaltungsprozesse wider und können daher **administrative Fehler** enthalten.  
- Die Originaldateien sind sehr groß (mehrere GB) und werden **nicht im Repository gespeichert**.  
- Nutzer*innen müssen die Daten bei Bedarf direkt von der offiziellen Quelle herunterladen.

---

## 3. Zweck der Nutzung in diesem Projekt

Die Daten werden ausschließlich für:

- Analyse staatlicher Beschaffungsprozesse  
- Bewertung von Wettbewerb und Effizienz  
- Untersuchung des Digitalisierungsgrades  
- Entwicklung von KI‑gestützten Modellen  
- Erstellung von Handlungsempfehlungen zur Automatisierung  

verwendet.
